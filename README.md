I like finishing things, not just prototyping them — a compiler in C, a stock predictor in a notebook, a couple of real-time web apps, and most recently a full production-grade iOS game built solo from the ground up.

**Right now:** deep in Swift & SwiftUI, shipping **[WordQuest](https://github.com/nambiropeter/WordQuest)** — a word search + trivia game with 8 themes, 1,000 levels each, local multiplayer over Bluetooth/Wi‑Fi, Game Center, iCloud sync, and a Dynamic Island Live Activity.
